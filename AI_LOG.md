# AI Log

## Tools
- ChatGPT — помощь с планированием проекта, реализацией API, разбором кода и тестированием.
- Swagger UI — проверка работы API вручную.
- Pytest — автоматическая проверка API и бизнес-логики.

## Key prompts
- Помощь в создании FastAPI-проекта и настройке PostgreSQL.
- Объяснение работы SQLAlchemy, Pydantic-схем и обработки платежей.
- Помощь в реализации промокодов, расчёта рассрочки, идемпотентности и банковских webhook.
- Помощь в написании тестов для проверки успешных и ошибочных сценариев.

## AI limitations
При реализации расчёта рассрочки возникла ошибка: расчёт графика платежей выполнялся вне проверки метода оплаты `installment`. При создании обычного платежа значение количества месяцев было `None`, из-за чего возникала ошибка при делении.

Проблема была обнаружена при проверке API и анализе ошибки. Расчёт графика был перенесён внутрь соответствующего условия, после чего обычные платежи стали обрабатываться корректно.
