# AI Log

## Tools
- ChatGPT — помощь в планировании проекта, настройке окружения, реализации API, разборе кода и подготовке тестов.
- Swagger UI — ручная проверка эндпоинтов и поведения API.
- Pytest — автоматическая проверка бизнес-логики и обработки ошибок.
- PostgreSQL и DBeaver — хранение данных и проверка содержимого базы.

## Key prompts
- «Помоги с нуля создать FastAPI-проект для тестового задания. Используем PostgreSQL, SQLAlchemy и Pydantic v2. Объясняй небольшими шагами, чтобы я понимал код и мог писать его самостоятельно».
- «Помоги реализовать создание платежа с промокодом KVITTO10, расчётом суммы в копейках и графиком рассрочки на 3, 6 и 12 месяцев. Сумма графика должна точно совпадать с суммой платежа».
- «Помоги написать pytest-тесты для API: проверка промокода, рассрочки, идемпотентности, запрещённых переходов статусов и запросов несуществующих платежей».

## AI limitations
При реализации расчёта рассрочки расчёт графика платежей оказался вне проверки метода оплаты `installment`. При создании обычного платежа количество месяцев было равно `None`, поэтому возникала ошибка при делении.

Проблему обнаружил при проверке API и анализе ошибки. Расчёт графика был перенесён внутрь соответствующего условия. После исправления обычные платежи стали обрабатываться корректно.

Ответы ИИ проверялись вручную через Swagger UI и автоматические тесты Pytest. Это помогло находить ошибки и проверять не только успешные сценарии, но и некорректные запросы.
